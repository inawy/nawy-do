# المطابقة مع Nawy Design & Engineering System

المرجع: [`inawy/design-system`](https://github.com/inawy/design-system) (قُرئ كاملًا في 2026-10-31: `AGENTS`، `ARCHITECTURE`، `TECHNOLOGY-STACK`، `ENGINEERING-STANDARDS`، `DESIGN-SYSTEM`، `tokens`، `components`، `foundations`، `patterns`، `DECISIONS/0001–0004`، المهارات، القالب).

**القاعدة:** ذلك المستودع هو المرجع المشترك لهوية وهندسة كل منتجات ناوي. هذا المنتج يلتزم به، وأي انحراف **مكتوب هنا بسببه** (هو يصف نفسه «Default, not dogma»). ترتيب مصادر الحقيقة عند التعارض كما في `AGENTS.md` عنده: الكود الفعلي والاختبارات ثم قرارات المنتج ثم وثائق المعمارية.

تصنيف كل بند (مصطلحات الحوكمة عنده): **مطابق** (مثبت بالكود) · **فجوة** (قرار بالتنفيذ، في مرحلة محددة) · **انحراف** (قرار مبرَّر بعدم المطابقة).

## سجل المعمارية المطلوب لكل منتج (`ARCHITECTURE.md` المرجع، قسم Required per-product architecture record)

| البند                                     | الجواب (من الكود الفعلي)                                                                                          |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| الاسم والغرض والنطاق                      | ناوي دو: مهام شخصية محلية أولًا، PWA، عربي أولًا                                                                  |
| runtime/framework/إصدارات                 | Vite 8 · React 19 · TypeScript 6 · Dexie 4 · Vitest 5 (راجع `package.json`)                                       |
| entry points وتدفق البيانات               | `main.tsx` → `App` (تركيب) → hooks (`features`) → منافذ `core/ports` → Dexie (`data`)                             |
| التخزين المحلي والسحابي، وما يُرسل للخادم | IndexedDB فقط (`nawy-do`، `nawy-do-snapshots`). **لا شيء يُرسل لأي خادم**                                         |
| auth والأمان                              | لا حسابات؛ لا أسرار؛ لا `dangerouslySetInnerHTML`؛ لا CDN                                                         |
| sync/backup/تعارضات                       | نسخ يدوي (تصدير/استيراد/استرجاع نسخ الأمان)؛ دمج بالسجل «الأحدث يفوز» مع tombstones (D-006) جاهز لمزامنة مستقبلية |
| integrations وAPI                         | لا شيء. (مستقبلًا: Google Drive عبر منفذ، المرحلة G)                                                              |
| أوامر البناء والاختبار والنشر             | `npm run lint/format:check/test/build/e2e`؛ النشر GitHub Pages من `main` إلى `do.nawy.app`                        |
| المخاطر والقيود                           | `KNOWN-LIMITATIONS.md`                                                                                            |
