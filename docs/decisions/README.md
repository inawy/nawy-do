# القرارات المعمارية (ADR)

القرارات من **D-001 إلى D-040** في [`../DECISIONS.md`](../DECISIONS.md) سجل تاريخي لا يُعدَّل (القرار المقبول لا يُعاد كتابته؛ يُضاف قرار جديد يشير إليه). رقم D-038 لم يُستخدم قط.

**كل قرار جديد من D-041 فصاعدًا ملف هنا** باسم `NNNN-عنوان-قصير.md` (الرقم هو رقم D نفسه بأربع خانات، مثل `0041-…`)، بالقالب الرسمي لـ `inawy/design-system`:

```markdown
# NNNN — العنوان

- **الحالة:** مقترح | مُعتمد | مُلغى بـ NNNN | يحلّ محل NNNN
- **التاريخ:** YYYY-MM-DD

## السياق

ما الذي دفع إلى القرار؟ القيود والأرقام.

## القرار

ما الذي سنفعله، بجملة واضحة.

## البدائل المرفوضة

ماذا نظرنا فيه ولماذا لا.

## النتائج

ما يصبح أسهل وما يصبح أصعب؛ ما الذي يلزم مراجعته ومتى.

## الدليل

اختبار أو قياس أو رابط أو PR يثبت أو يدعم القرار.
```

القواعد: قرار واحد في ملف واحد؛ الدليل مطلوب لأي ادعاء عن الأداء أو التوافق؛ تغيير قرار = قرار جديد يحلّ محلّه ويُحدَّث سطر **الحالة** في القديم فقط.
