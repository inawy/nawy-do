# خطة البناء — Nawy To Do

القاعدة: لا انتقال لمرحلة قبل نجاح بوابتها (lint + format + test + build). الأنقى والأخطر أولًا.

## المرحلة 0 — الأساس (قيد التنفيذ)

Vite + React + TS صارم، Vitest، ESLint + Prettier، قواعد الطبقات، CI وPages، `brand.json`.
**لم يتحقق بعد:** أن CI أخضر (لم يُشغَّل البناء محليًا: لا npm).

## المرحلة 1 — نموذج المهمة (`core/model`)

أنواع `Task`، إنشاء/تعديل/إنجاز/إعادة فتح، tombstone، دمج. اختبارات: ترتيب `updatedAt`، الدمج تبادلي وidempotent، عدم إحياء المحذوف.
(الجزء الأول موجود في هذا الفرع.)

## المرحلة 2 — التخزين (`data`)

Dexie v1 (`tasks`, `meta`)، CRUD بـ tombstones، تصدير/استيراد envelope يرفض الإصدار الأحدث، لقطات احتياطية قبل الترحيل، اختبارات بـ `fake-indexeddb`.

## المرحلة 3 — الواجهة الأولى (قيد التنفيذ)

خانة «ناوي تعمل إيه؟»، قائمة النوايا، إنجاز/تراجع، حذف مع تراجع. RTL، لمس ≥ 44px، وضع داكن.
