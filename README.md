# Nawy To Do · ناوي دو

> **ناوي تعمل إيه؟** · What are you up to?

مهام شخصية سريعة وخصوصية، محلية أولًا وتعمل بلا إنترنت. جزء من عائلة ناوي.

## الحالة

🚧 **قيد البناء — المراحل 0–3.** الواجهة الأولى: إضافة نية، إنجاز وتراجع، حذف مع تراجع.
النطاق المخطط: `do.nawy.app`. انظر `docs/BUILD_PLAN.md`.

## التشغيل

```bash
npm install
npm run dev
npm test
```

المعمارية والقواعد: `AGENTS.md` و`docs/DECISIONS.md`.
