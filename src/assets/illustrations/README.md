# Empty-state illustrations

| File         | Source                                                                   | Used for                        |
| ------------ | ------------------------------------------------------------------------ | ------------------------------- |
| `empty.svg`  | unDraw «no data» (via the MIT-licensed `balazser/undraw-svg-collection`) | an empty list                   |
| `search.svg` | unDraw «search»                                                          | a search with no results        |
| `trash.svg`  | unDraw «text files»                                                      | an empty trash                  |
| `inbox.svg`  | unDraw «mailbox»                                                         | nothing due (today / scheduled) |
| `done.svg`   | drawn for Nawy (ours)                                                    | every task completed            |

unDraw illustrations are free for personal and commercial use without attribution. They are
changed only in colour: each fill is a CSS variable (`--ill-accent`, `--ill-line`, `--ill-mid`,
`--ill-soft`, `--ill-paper`) so they follow the appearance (light, dark, black).

**Rule (the team's content standard):** objects and abstract shapes only. No people, no bodies, no
couples or any figure that conflicts with the app's values. When adding one, look at it first
(render it) and keep it to the same style.
